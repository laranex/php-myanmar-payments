A framework-agnostic PHP SDK for Myanmar payment gateways (KBZ Pay, Wave Money, AYA Payment Gateway, Yoma MMQR and CyberSource), with typed requests and results, verified callbacks and exact amounts instead of floats. Built for humans and AI agents.
